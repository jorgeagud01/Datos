# Paquete de capacitación: IA práctica con Gemini

Este repo contiene el paquete completo listo para importar a Google Slides/manual conversion. Incluye:

- /slides/: contenido por diapositiva y notas del ponente para las 8 sesiones.
- /emails/: plantillas de comunicación (invitación, recordatorios, seguimiento, certificado).
- /prompts/: prompts listos para Gemini y prompts text-to-image para generar imágenes.
- /resources/: datasets de ejemplo, ejercicios y quizzes.
- /images/: archivos placeholder y nombres sugeridos (las imágenes finales se generan con los prompts en /prompts/prompts_text_to_image.md).

Branding: paleta de Google (sin logo). Para generar los PNG finales, usa los prompts en /prompts/prompts_text_to_image.md con tu herramienta de text-to-image preferida y sube los resultados a /images/ como se indica.

Cómo convertir a Google Slides
1. Crear un PPTX a partir de las carpetas /slides/ (puedes usar herramientas como Beautiful.AI, Deckset, o copiar/pegar manualmente). También puedes usar Pandoc o herramientas de automatización (ver pasos en README).
2. Subir el PPTX a Google Drive > Abrir con > Google Slides.

Commit incluye contenido textual extenso para cada sesión — revisa y solicita ajustes si quieres más detalle en alguna sesión.
